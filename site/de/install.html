Voraussetzungen

  • Ein 64-Bit-PC (x64).
  • Windows 10 oder 11. Getestet unter Windows 11.
  • Linux mit glibc 2.35 oder neuer, zum Beispiel Ubuntu 22.04, Debian 12, Fedora 36 oder neuer. Getestet unter Debian 13.

.NET oder andere Programme musst du nicht installieren, alles Nötige ist dabei.

Windows mit Installer

  1. Lade just-practise-win-Setup.exe herunter.
  2. Starte die Datei. Sie installiert just practise nur für dein Benutzerkonto, du brauchst also keine Administratorrechte, und startet danach die App.
  3. Später startest du just practise über das Startmenü.

Der Computer wurde durch Windows geschützt: just practise ist nicht signiert, deshalb warnt Microsoft Defender SmartScreen beim ersten Mal. Klicke auf Weitere Informationen und dann auf Trotzdem ausführen. Wenn du sichergehen willst, dass die Datei die richtige ist, prüfe vorher den Download.

Windows ohne Installation

  1. Lade just-practise-win-Portable.exe herunter und lege die Datei ab, wo du willst, zum Beispiel auf einem USB-Stick.
  2. Starte sie per Doppelklick. SmartScreen warnt wie oben beschrieben.

Der erste Start dauert etwas länger, weil sich die Datei entpackt. Diese Variante aktualisiert sich nicht selbst: Lade bei einer neuen Version einfach die neue Datei herunter.

Linux

just practise gibt es als AppImage, eine einzelne Datei, die auf den meisten Distributionen läuft.

  1. Lade just-practise.AppImage herunter.
  2. Mache die Datei ausführbar, im Terminal oder in den Dateieigenschaften deines Dateimanagers: 
    chmod +x just-practise.AppImage
  3. Starte sie per Doppelklick oder im Terminal: 
    ./just-practise.AppImage

Wenn sie nicht startet

AppImages brauchen FUSE 2. Die meisten Desktop-Distributionen bringen es mit, sonst installierst du es so:

DistributionBefehl
Ubuntu 24.04 oder neuer, Debian 13sudo apt install libfuse2t64
Ubuntu 22.04, Debian 12sudo apt install libfuse2
Fedorasudo dnf install fuse-libs

Ohne FUSE startest du sie so:

./just-practise.AppImage --appimage-extract-and-run

Download prüfen

Zu jedem Release gehört eine Datei SHA256SUMS mit den Prüfsummen aller Dateien. Lade sie in denselben Ordner wie deine Datei und vergleiche.

Unter Linux:

sha256sum --check --ignore-missing SHA256SUMS

Unter Windows in der PowerShell:

Get-FileHash .\just-practise-win-Setup.exe

Der Hash muss mit der Zeile für diese Datei in SHA256SUMS übereinstimmen (Groß- und Kleinschreibung spielt keine Rolle).

Updates

just practise sucht nie von sich aus nach Updates. Öffne dafür die Einstellungen (Strg+,) und klicke auf Nach Updates suchen. Gibt es eine neue Version, entscheidest du, ob sie heruntergeladen wird. Installiert wird sie beim nächsten Start der App, nie mitten im Üben.

Das funktioniert mit dem Windows-Installer und dem Linux-AppImage. Die portable Windows-Variante verlinkt stattdessen die Download-Seite.

Wo deine Daten liegen

  • Tempo und Lautstärke einer Datei stehen neben deiner Musik in einer kleinen Datei mit dem Namen des Stücks und der Endung .jps, zum Beispiel Autumn Leaves.jps. Sie entsteht erst, wenn du etwas änderst. So wandern deine Einstellungen mit, wenn du den Ordner auf einen anderen Rechner kopierst.
  • Einstellungen und die Liste deiner Musikordner:
    SystemEinstellungenCache (darf jederzeit gelöscht werden)
    Windows%APPDATA%\just-practise%LOCALAPPDATA%\just-practise
    Linux~/.config/just-practise~/.cache/just-practise

just practise sendet nichts. Ins Internet geht die App nur, wenn du nach Updates suchst.

Deinstallieren

  • Windows mit Installer: Einstellungen › Apps › Installierte Apps › just practise › Deinstallieren.
  • Windows portabel und Linux: Lösche die Datei.

Um alles zu entfernen, lösche zusätzlich den oben genannten Einstellungsordner und, wenn du willst, die .jps-Dateien in deinen Musikordnern.
