Requirements

  • A 64-bit PC (x64). ARM devices are not supported yet.
  • Windows 10 or 11. Tested on Windows 11.
  • Linux with glibc 2.35 or newer, for example Ubuntu 22.04, Debian 12, Fedora 36 or newer. Tested on Debian 13.
  • macOS is not supported yet.

You do not need to install .NET or anything else; everything the app needs is included.

Windows with the installer

  1. Download just-practise-win-Setup.exe.
  2. Run it. It installs just practise for your user account only, so you do not need administrator rights, and starts the app.
  3. After that, start just practise from the Start menu.

Windows protected your PC: just practise is not signed yet, so Microsoft Defender SmartScreen warns you the first time. Click More info and then Run anyway. If you want to be sure the file is the right one, check the download first.

Windows without installation

  1. Download just-practise-win-Portable.exe and put it wherever you like, for example on a USB stick.
  2. Double-click it to start. SmartScreen warns you as described above.

The first start takes a little longer because the file unpacks itself. This version does not update itself: download the new file when there is a new version.

Linux

just practise comes as an AppImage, a single file that runs on most distributions.

  1. Download just-practise.AppImage.
  2. Make it executable, in a terminal or in the file properties of your file manager: 
    chmod +x just-practise.AppImage
  3. Start it with a double-click or from the terminal: 
    ./just-practise.AppImage

If it does not start

AppImages need FUSE 2. Most desktop distributions have it; if not, install it:

DistributionCommand
Ubuntu 24.04 or newer, Debian 13sudo apt install libfuse2t64
Ubuntu 22.04, Debian 12sudo apt install libfuse2
Fedorasudo dnf install fuse-libs

Without FUSE you can still start it like this:

./just-practise.AppImage --appimage-extract-and-run

Check the download

Each release has a file SHA256SUMS with the checksums of all files. Download it into the same folder as your file and compare.

On Linux:

sha256sum --check --ignore-missing SHA256SUMS

On Windows, in PowerShell:

Get-FileHash .\just-practise-win-Setup.exe

The hash must match the line for that file in SHA256SUMS (upper or lower case does not matter).

Updates

just practise never looks for updates on its own. To update, open the settings (Ctrl+,) and click Check for updates. If there is a new version, you decide whether to download it. It is installed the next time you start the app, never in the middle of practising.

This works for the Windows installer and the Linux AppImage. The portable Windows version links to the download page instead.

Where your data is

  • Tempo and volume of a file are stored next to your music in a small file with the name of the piece and the ending .jps, for example Autumn Leaves.jps. It is only created when you change something. So your settings travel with the folder when you copy it to another computer.
  • Settings and your list of music folders:
    SystemSettingsCache (can be deleted at any time)
    Windows%APPDATA%\just-practise%LOCALAPPDATA%\just-practise
    Linux~/.config/just-practise~/.cache/just-practise

just practise does not send anything anywhere. It only goes online when you check for updates.

Uninstall

  • Windows with the installer: Settings › Apps › Installed apps › just practise › Uninstall.
  • Windows portable and Linux: delete the file.

To remove everything, also delete the settings folder listed above and, if you like, the .jps files in your music folders.
