## Repository state

The project is in the concept phase and has no source code yet. Besides `README.md`, an MIT `LICENSE` and a `.gitignore` from GitHub's `Dotnet.gitignore` template, it contains the concept documents (in German):

- `docs/funktionen.md`: the feature concept (audio player, practice timer, metronome, tuner, keyboard shortcuts, language and music notation, app settings)
- `docs/technologie.md`: technical requirements and open points for the technology decision

The technology stack is not decided yet. The `.gitignore` template is not a decision for .NET. Features and the tech choice are discussed with the user before anything is set up.

There are no build, lint, or test commands to document until a project is added. Once one exists (e.g. a `.sln`/`.csproj`), update this file with the actual commands and a short architecture overview.
